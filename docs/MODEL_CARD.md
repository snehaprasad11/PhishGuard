# Model card

The measured numbers live in [`models/model_card.html`](../models/model_card.html), which is
generated by `python -m training.evaluate` from the evaluation run. Nothing in it is typed by
hand, so it cannot drift from the model it describes. This page covers what does not change
from run to run.

The generated card covers both models: the URL model first, then the text model, which has
its own data, results, comparison with a bag-of-words model, and limitations.

## Intended use

Helping a person decide whether a link is likely to be phishing before they act on it. The
model sees only the text of a URL. It is an aid to judgement, not a guarantee, and its output
should always be shown with the reasons behind it.

## Out of scope

- Deciding automatically to block or allow a page.
- Detecting malware downloads, scams without a link, or phishing delivered inside a
  legitimate platform (form builders, site builders, URL shorteners).
- Judging page content. Neither model reads the page: the URL model sees an address, and the
  text model sees only a message the user pastes.

## How to read the generated card

- **Held-out test results** come from sites the model never saw, with phishing newer than
  anything in training.
- **Operating point** shows the false-positive rate on both validation (where the threshold was
  chosen) and test (where it was only applied).
- **Results by URL shape** separates bare-host URLs from URLs with a path, because the two
  behave differently.
- **Checks outside the training distribution** lists every well-known legitimate page the
  model would wrongly flag, and recall on an independent phishing feed.
- **Alternatives considered** shows what a stronger but less explainable model scores.

## Ethical and practical cautions

- False positives on real banks and sign-in pages erode trust quickly. They are tracked by name
  in the generated card.
- A "looks safe" result must never be presented as proof of safety.
- Attackers adapt to published features. Performance degrades between retrains.
